# 🔤 Módulo: Manipulação de Strings

Este módulo reúne scripts focados na transformação, análise, busca e formatação de dados do tipo texto (strings) utilizando métodos nativos do Python.

---

## 🛠️ Exercícios Incluídos

### 1. `manipulacao_nome_completo.py`
* **Objetivo:** Coletar o nome do usuário e aplicar transformações de caixa e fatiamento.
* **Conceitos Práticos:** `lower()`, `upper()`, remoção de espaços vazios com `replace()` para contagem exata e isolamento do primeiro nome via `split()`.

### 2. `analisador_casas_decimais.py`
* **Objetivo:** Receber um número de 0 a 9999 e decompor suas ordens numéricas.
* **Conceitos Práticos:** Tratamento do input como string, padronização do tamanho de texto via `zfill()` e identificação direta de Unidade, Dezena, Centena e Milhar.

### 3. `analisador_frequencia_letras.py`
* **Objetivo:** Mapear a presença e a posição de caracteres específicos dentro de uma frase.
* **Conceitos Práticos:** Medição de comprimento total com `len()`, contagem de ocorrências com `count()`, e localização da primeira (`find()`) e última (`rfind() ou percorrer com a ultima posição do find`) ocorrência da letra "A".
