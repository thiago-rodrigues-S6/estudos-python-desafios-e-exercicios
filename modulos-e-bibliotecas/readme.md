# 📚 Módulo: Utilizando Bibliotecas Nativas e Utilitários

Este módulo reúne exercícios focados na importação e manipulação de bibliotecas nativas e específicas de ambiente em Python, expandindo as capacidades do código para matemática avançada, aleatoriedade, manipulação de tempo e multimídia.

---

## 🛠️ Exercícios Incluídos

### 1. `geometria_com_math.py`
* **Objetivo:** Calcular a hipotenusa de um triângulo retângulo e as funções trigonométricas de um ângulo qualquer.
* **Conceitos Práticos:** Uso do módulo `math` para cálculos de hipotenusa, conversão de graus/radianos e obtenção de Seno, Cosseno e Tangente.

### 2. `sorteio_e_ordem_apresentacao.py`
* **Objetivo:** Automatizar o sorteio de um aluno individual e a ordem de apresentação de um grupo.
* **Conceitos Práticos:** Manipulação de listas com o módulo `random` através das funções `choice()` (seleção única) e `shuffle()` (embaralhamento).

### 3. `reprodutor_audio_colab.py`
* **Objetivo:** Carregar um arquivo de áudio local e executá-lo diretamente na interface do Google Colab.
* **Conceitos Práticos:** Integração com utilitários de ambiente usando `google.colab.files` para upload e `IPython.display.Audio` para reprodução de áudio.

### 4. `simulador_desligamento_sistema.py`
* **Objetivo:** Simular o desligamento seguro de um sistema com efeitos visuais temporizados no terminal.
* **Conceitos Práticos:** Uso do módulo `time` (especificamente `time.sleep()`) para criar intervalos de atraso controlados entre as mensagens de aviso e a despedida final.
